    Catalog Maintenance

    Catalog Maintenance

    Maintain stored images and update the owner on every paper pack.

    What does Move Images to Folder do?

    Moves images currently stored inside this browser into your selected image folder. Use this after choosing an image folder, especially before sharing the catalog with someone else.

    What does Repair Image Links do?

    Rescans matching paper-pack folders, repairs broken image references, and reconnects fallback backup images to files already in the selected folder. It does not copy, overwrite, or delete image files.

    What do Generate Missing Thumbnails actions do?

    Scans catalog-referenced images in the selected Paper or Card folder, leaves every usable .thumb.jpg unchanged, repairs empty thumbnails, and creates thumbnails only where they are missing.

    Backup & Restore

    Catalog Backup and Restore

    Export or restore catalog data for sharing, safekeeping, or moving browsers. Exports are saved in the selected image folder when available.

    iPad Import Diagnostic Report

    By default, incremental import adds paper packs, colors, and Cards whose IDs are missing and leaves matching IDs unchanged. Select this option for an overlay import that replaces matching IDs while retaining unrelated catalog entries. Cards that look alike but have different IDs remain separate.

    If an imported backup is missing images, choose Low-Memory Diagnostic and select the same backup. It scans the file in small pieces without importing or changing the catalog. When it finishes, use Copy Debug Report and send the copied text to the app developer.

    How do I share this catalog with an iPad or another computer?
    1. On the computer with the complete catalog, choose Export Compact iPad Backup if the other person needs images included, or Export Backup if they will also connect to the same image folder.
    2. Send the downloaded backup file to the other person.
    3. Have them open the shared app URL: https://ninabarley47-gh.github.io/card-supply-catalog/.
    4. In Settings, choose Import Backup and select the file.
    5. On iPad, open the app in Safari and use Share, then Add to Home Screen.
