## When a milestone is reached
Tag it (v0.2.0)
    In the VS Graph:
    Right-click the highlighted commit—the one currently marked by HEAD.
    Choose Create Tag.
    Enter the version number e.g. v0.1.0
Push the tag
    Press Ctrl+Shift+P.
    Start typing Git: Push Tags.
    Click that command when it appears.
    If VS Code asks which remote to use, choose origin.
Create a GitHub Release in Git
    Open your repository on GitHub:
    Click Releases.
    Click Draft a new release.
    In Choose a tag, select the tag you just created
    Update the title and release notes
    Leave Set as a pre-release unchecked.
    Click Publish release.
